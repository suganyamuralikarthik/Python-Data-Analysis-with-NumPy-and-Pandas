# Python Data Analysis with NumPy and Pandas

## Project Overview

This project covers the fundamentals of **NumPy and Pandas** for data analysis. It includes array operations, Pandas Series, DataFrame exploration, filtering, aggregation, and data manipulation.

## Technologies Used

* Python
* NumPy
* Pandas
* Jupyter Notebook / Google Colab

## NumPy

The project includes:

* Creating 1D and 2D NumPy arrays
* Checking shape, data type, and size
* Converting Celsius to Fahrenheit
* Finding maximum, minimum, and mean temperatures
* Array indexing and slicing

## Pandas Series

The project demonstrates:

* Creating a Series with custom indexes
* Using `.loc` and `.iloc`
* Boolean filtering
* Updating and removing values
* Calculating CGPA

## Pandas DataFrame

A transaction dataset was created with:

* `TransactionID`
* `ProductCategory`
* `Region`
* `Amount`

### Data Exploration

The DataFrame was analyzed using:

* `head()` and `tail()`
* `shape`, `columns`, and `dtypes`
* Column selection
* `iloc` for column slicing
* Conditional filtering
* `value_counts()`
* `unique()`
* `groupby()` with `mean()`

### Data Manipulation

The transaction data was modified by:

* Updating TransactionID 102 amount to **165**
* Adding a `Discount` column using 10% of Amount
* Removing TransactionID 109
* Deleting the `Discount` column

## Key Learning Outcomes

This project provided practical experience with **NumPy arrays, Pandas Series, DataFrames, indexing, slicing, filtering, aggregation, and data manipulation**.

## Conclusion

This project demonstrates the use of **NumPy and Pandas for fundamental data analysis tasks**, providing a foundation for working with numerical and structured datasets in Python.
